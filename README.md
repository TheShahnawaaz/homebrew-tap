# homebrew-tap

Official Homebrew tap for Aura macOS assistant.

## Installation

Install directly with:

```bash
brew install TheShahnawaaz/tap/aura
```

Or tap first and then install:

```bash
brew tap TheShahnawaaz/tap
brew install aura
```
